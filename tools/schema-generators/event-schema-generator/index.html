What Is Event Schema?

    
Event schema is structured data that describes an event people can attend: what it is, when it starts, where it happens and how to get tickets. Google can use it to list your event in its event search experience, with dates and venue shown at a glance.

    
This event schema generator writes the Event type with a nested Place, Offer, organizer and performers.

Handling Changes to Your Event

    
    
      
  • Cancelled: set the status to Cancelled and keep the original date.
    • 
      
  • Postponed with no new date: set Postponed and keep the original date.
    • 
      
  • Rescheduled: set the new start date, choose Rescheduled and add the original date.
    • 
      
  • Online only: Google's event results only support events at a physical place, so purely virtual events will not appear.

Frequently Asked Questions

    
1Can I use event schema for webinars or online events?
Google's event rich results only support events that happen at a physical location. You can still describe an online event with schema.org, but it will not appear in Google's event listings.

    
2How do I mark up an event that repeats every week?
Add a separate Event block for each date, each with its own start date. Do not put several dates in one Event.

    
3What price should I use if there are several ticket types?
Google asks for the lowest available price, including any fees. Use 0 for free events.

    
4Is my event data stored?
No. The event schema generator runs entirely in your browser and nothing is uploaded.
