What Is Breadcrumb Schema?

    
Breadcrumb schema is structured data that shows where a page sits in your site. It uses the BreadcrumbList type with one ListItem per level, such as Home, then Blog, then the post.

    
Google can use it to show a clean trail of categories in your search result instead of a long URL, which helps people understand your page before they click.

Google's Breadcrumb Rules

    

      
RuleDetails

      
        
At least two itemsA single item trail is not valid

        
positionStarts at 1 for the top level and counts up

        
nameThe label shown for each step

        
itemThe URL of each step. Optional for the last item, where Google uses the page URL

        
Multiple trailsAllowed if a page sits in more than one category

Tips for Better Breadcrumbs

    
    
      
  • Show a visible breadcrumb on the page too. Markup should describe what users see.
    • 
      
  • Base the trail on how people browse your site, not only on your URL folders.
    • 
      
  • Keep names short. One to three words per step reads best.
    • 
      
  • Breadcrumbs also pass internal links up to category pages, which helps them rank.

Frequently Asked Questions

    
1Do breadcrumbs still show in Google results?
Google still supports breadcrumb structured data and lists it in its search gallery. How the trail appears can vary by device and query, but valid markup keeps your page eligible.

    
2Should the last breadcrumb have a URL?
It is optional. If you leave out the item URL for the last step, Google uses the URL of the page the markup is on. Tick the option above to do this.

    
3Can a page have more than one breadcrumb trail?
Yes. If a product or post belongs to two categories, you can add two BreadcrumbList blocks. Google allows multiple trails for one page.

    
4Is anything I enter uploaded?
No. The breadcrumb schema generator runs in your browser. URLs you paste are only read on your device.
