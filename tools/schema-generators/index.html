Which Schema Generator Do You Need?

  • A shop, clinic, cafe or office? Use the Local Business Schema Generator.
  • Selling products? Use the Product Schema Generator for price, stock and ratings.
  • Publishing posts or news? Use the Article Schema Generator, plus the Breadcrumb Schema Generator.
  • Your brand and home page? Use the Organization Schema Generator.
  • Running a concert, workshop or conference? Use the Event Schema Generator.
  • Got a video on the page? Use the Video Schema Generator to add key moments too.

Every generator checks your input against Google's current structured data rules as you type, and outputs clean JSON LD you can paste into any page or CMS.

Why Is There No FAQ Schema Generator?

Google stopped showing FAQ rich results in May 2026, after limiting them to a few government and health sites in 2023. HowTo rich results were removed in 2023 too. FAQPage is still a valid schema.org type, but it no longer earns a special result in Google, so we focus on the types that still do.

New to structured data? Start with what is schema markup and how to add schema markup with JSON LD.

Frequently Asked Questions

1Are these schema generators free?

Yes. Every generator is free, needs no signup, and has no usage limits.

2Where do I paste the JSON LD code?

Paste it anywhere in the HTML of the page it describes, usually in the head. In WordPress you can use a custom HTML block or a header code plugin. Then test the page in Google's Rich Results Test.

3Is my data safe?

Yes. All generators run entirely in your browser. Nothing you type is uploaded or stored.
