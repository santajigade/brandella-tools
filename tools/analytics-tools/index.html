Which Analytics Tool Do You Need?

  • Tagging a campaign link? Use the UTM Builder, or the Bulk UTM Builder for many pages and channels at once.
  • Sharing a link full of tracking codes? Clean it with the UTM Parameter Remover.
  • Tracking leads, sign ups or sales? Write the code with the GA4 Event Code Generator.
  • Serving visitors in Europe? Set up Google tags correctly with the Consent Mode v2 Generator.
  • Filtering reports? Check your pattern in the GA4 Regex Tester before you save it.
  • Planning an experiment? Work out visitors and days with the A/B Test Sample Size Calculator.

Every tool follows Google's current GA4 documentation and checks your input as you type, so you catch problems before they reach your reports.

New to campaign tracking? Read UTM parameters explained and GA4 metrics explained for beginners.

Frequently Asked Questions

1Are these analytics tools free?

Yes. Every tool is free, needs no signup, and has no usage limits.

2Do I need a Google Analytics account to use them?

No. The tools build links and code you can use anywhere. You only need GA4 or Google Tag Manager when you put the code or links to work.

3Is my data safe?

Yes. All tools run entirely in your browser. URLs, event names and numbers you enter are never uploaded or stored.
