What Is a GA4 Event Code Generator?

    
Everything Google Analytics 4 records is an event. Page views and scrolls are collected for you, but leads, sign ups, purchases and button clicks usually need a few lines of code. This generator writes that code for you, either as a gtag() call for sites using the Google tag, or as a dataLayer.push() for sites using Google Tag Manager.

    
Small mistakes break events quietly. A space in a name, a value sent as text with a currency symbol, or a missing currency can mean GA4 drops the data or shows zero revenue. The checker flags these problems as you type, using Google's event naming rules and event collection limits.

Tips for Reliable Event Tracking

    
    
      
  • Use recommended events first. Names like generate_lead and purchase unlock built in reports. See the full list in Google's recommended events reference.
    • 
      
  • Keep names lowercase. Names are case sensitive, so Sign_Up and sign_up are two separate events.
    • 
      
  • Register custom parameters. To see a custom parameter in reports, create a custom dimension for it in GA4 Admin.
    • 
      
  • Mark key events. Sending an event does not make it a conversion. Mark it as a key event in GA4 once it shows up.
    • 
      
  • Clear old ecommerce data in GTM. The ecommerce: null push stops items from one event leaking into the next.
    •

Frequently Asked Questions

    
1Should I use gtag.js or dataLayer code?
Use gtag.js code if your site loads the Google tag directly. Use dataLayer.push code if you manage tags in Google Tag Manager, then create a GA4 Event tag with a Custom Event trigger that matches the event name.

    
2Why is my event not showing in GA4 reports?
Standard reports can take up to a day to update. Check DebugView or the Realtime report first. If the event is missing there, look for a name with spaces or capitals, a reserved name, or code that runs before the Google tag loads.

    
3Do I need to send currency with value?
Yes. Google's reference says currency is required whenever you set value. Without it, revenue and value metrics are not calculated correctly.

    
4Is my event data uploaded?
No. The code is generated in your browser and nothing you type is sent to a server.
