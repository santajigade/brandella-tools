What Is an Open Graph Preview?

When someone shares your page on Facebook, LinkedIn, WhatsApp or X, the app reads a few meta tags in your HTML to build the link card: a title, a short description and an image. These are Open Graph tags, defined by the Open Graph protocol. If they are missing or wrong, your link shows up with a random picture, a cut off title or no image at all.

This tool reads the tags straight from the HTML you paste, shows how each app is likely to display the link, and lists exactly what to fix. Nothing is fetched from your site, so it also works for pages that are not live yet.

How to Use the Open Graph Preview

  1. Copy your page source. Open the page, view its source and copy the head section, or paste the whole page.
  2. Paste it into the box. The previews and the tag check update as you type.
  3. Add the share image from your device to see it in each card and check its size and shape.
  4. Work through the list of issues, update your tags, and paste again to confirm.

Tips for Better Link Previews

  • Design a share image for each key page. A clear headline on the image gets more clicks than a generic logo.
  • Keep text away from the edges. Some apps crop the card to 2:1 or show a square thumbnail.
  • Refresh the cache after changes. Apps store previews, so use the Facebook Sharing Debugger or LinkedIn Post Inspector to fetch the new version.
  • Use one image URL per version. If you change the picture, change its file name too, so old copies are not reused.

Frequently Asked Questions

1What size should an Open Graph image be?

Use 1200 x 630 pixels, a 1.91:1 shape. Meta recommends at least that size for sharp cards, needs at least 600 x 315 for the large layout, and rejects images smaller than 200 x 200 pixels.

2Why is my old image still showing after I changed it?

Facebook, LinkedIn and other apps cache link previews. Run the page through the Facebook Sharing Debugger or LinkedIn Post Inspector to fetch it again, and give the new image a new file name.

3Does X use Open Graph tags?

Yes. X reads its own twitter tags first and falls back to Open Graph for the title, description and image. You still need twitter:card set to summary_large_image for the big image layout.

4Does this tool visit my website?

No. It only reads the HTML you paste. The share image is loaded from its web address only if you tick that option, and an image you pick from your device stays on your device.
