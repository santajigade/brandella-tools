What Is an llms.txt File?

    
An llms.txt file is a short Markdown file at the root of your site that tells large language models what your site is about and which pages matter most. Think of it as a hand picked map for AI tools, written in plain text instead of XML.

    
The format comes from the llmstxt.org proposal. Coding assistants, AI agents and some chat tools read it to find clean, useful pages without crawling your whole site. This generator builds the file in your browser and checks it against that format as you type.

Tips for a Useful llms.txt

    
    
      
  • Pick your best pages, not every page. The file is a shortlist. Your XML sitemap already lists everything.
    • 
      
  • Write notes that answer "why read this?" Five to twelve words is plenty.
    • 
      
  • Group by what people need, such as guides, pricing, docs and policies, rather than by site folder.
    • 
      
  • Be honest about the payoff. Google says its search and AI features do not use llms.txt, so it will neither help nor harm your Google rankings. See the Google AI optimization guide. The file is mainly for other AI tools and agents.
    • 
      
  • Keep it current. Update it when you publish a cornerstone page or retire an old one.
    •

Frequently Asked Questions

    
1Does llms.txt help my Google rankings?
No. Google says Google Search and its AI features do not use llms.txt, so the file neither helps nor harms your rankings there. It is aimed at other AI tools, agents and coding assistants that choose to read it.

    
2Where do I put the llms.txt file?
Upload it to the root folder of your site so it opens at yourdomain.com/llms.txt. On WordPress you can upload it with your host's file manager or an SEO plugin that supports llms.txt.

    
3Is llms.txt the same as robots.txt?
No. robots.txt tells crawlers what they may not visit. llms.txt is a reading list of pages you recommend. Blocking or allowing AI crawlers is still done in robots.txt.

    
4How many links should llms.txt have?
There is no fixed limit, but a focused list of your 10 to 100 most useful pages works best. Put nice to have pages under the Optional section so AI tools with little room can skip them.
