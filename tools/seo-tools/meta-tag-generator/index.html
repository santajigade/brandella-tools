What Are Meta Tags?

    
Meta tags are small pieces of HTML in a page's <head> that describe the page to search engines and social networks. Visitors do not see them on the page itself.

    
They control the blue title and description in Google, whether a page can be indexed, which URL is the main version, and how the link looks when someone shares it.

Frequently Asked Questions

    
1Which meta tags are most important for SEO?
The title tag and meta description matter most for how your result looks in Google. The robots and canonical tags matter for whether and how the page is indexed.

    
2Does the meta keywords tag help SEO?
No. Google has ignored the meta keywords tag for many years, so this meta tag generator does not include it.

    
3What is the difference between Open Graph and Twitter Card tags?
Open Graph tags control link previews on Facebook, LinkedIn, WhatsApp and many other apps. Twitter Card tags do the same for X, which also falls back to Open Graph when its own tags are missing.

    
4I use WordPress. Do I still need this?
SEO plugins like Rank Math and Yoast create these tags for you. The generator is still useful for custom pages, landing pages, static sites and for checking what your plugin should output.
