What Does a Robots.txt Tester Do?

A robots.txt tester tells you whether a crawler is allowed to visit a URL on your site. It reads your file the same way Google does: it picks the right group for the crawler, compares every rule with the URL, and lets the most specific rule decide.

Google Search Console no longer has its old robots.txt tester, so a quick private check like this is the fastest way to catch a rule that blocks pages you want in search. Everything runs in your browser, and nothing is fetched from your site.

How to Use the Robots.txt Tester

  1. Paste your robots.txt. Open yourdomain.com/robots.txt in a browser and copy the whole file.
  2. Pick a crawler, such as Googlebot, Bingbot or an AI bot, or type a custom user agent.
  3. List the URLs to test, one per line. Full URLs and paths both work.
  4. Read the results. Each URL shows Allowed or Blocked and the line that decided it.
  5. Fix the file check items, such as rules Google ignores or paths without a leading slash.

How Google Decides Which Rule Wins

SituationWhat happens
Crawler has its own groupIt uses only that group and ignores *
Several groups name the same crawlerTheir rules are merged into one
Allow and Disallow both matchThe longer, more specific path wins
Two matching rules are the same lengthAllow wins, as the least restrictive rule
* in a pathMatches any characters, including none
$ at the endThe URL must end exactly there
Upper and lower casePaths are case sensitive, so /Shop and /shop differ

These are the rules in Google's robots.txt specification, which follows the RFC 9309 standard. Crawlers like Googlebot-Image fall back to the Googlebot group when they have none of their own, and the tester copies that behaviour.

Tips for Testing

  • Test pages you want ranked, not only pages you meant to block. Accidental blocks are the costly mistake.
  • Include query strings. Rules like /*?sort= only match URLs with that parameter.
  • Check each crawler. A Googlebot group means Google skips your general rules, which surprises many site owners.
  • Remember the cache. Google usually caches robots.txt for up to a day, so changes take a little time to apply.

Frequently Asked Questions

1Why does Googlebot ignore my rules for all user agents?

A crawler only follows the most specific group that names it. If your file has a Googlebot group, Google uses that group alone and skips the general group, so copy any shared rules into it.

2Does a blocked URL disappear from Google?

Not always. Google can still index a blocked URL without its content if other pages link to it. Use a noindex tag on a crawlable page to keep it out of results.

3Is the tester the same as Google's?

It follows Google's published rules for groups, wildcards and rule priority. For a final check on a live page, use the URL Inspection tool in Search Console.

4Is my robots.txt sent anywhere?

No. The file and URLs you paste are tested inside your browser. Nothing is uploaded or fetched from your site.
